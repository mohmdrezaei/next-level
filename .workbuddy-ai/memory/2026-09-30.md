## Fix: uploaded product photo changed colour in light mode

**Report:** «چرا عکس محصولو آپلود میکنم رنگش عوض میشه» — red upload `#c8102e` rendered pink `#ef90a7`.

**Root cause:** `globals.css` had a blanket rule
`html.light img:not(.media-natural) { filter: invert(1) hue-rotate(180deg) ... }`.
It was written for the generated dark SVG art, but `media-natural` was never applied anywhere —
so every uploaded photo (data URL) got inverted.

**Fix (opt-in inversion):**
- New `src/lib/media.ts` → `isGeneratedArt(src)` / `mediaClassFor(src)`.
  Generated art = paths starting with `/products/`, `/collections/`, `/art/`.
- `globals.css` now targets only `html.light img.media-invertible:not(.media-natural)`.
- Every `<img>` that renders product/category art now spreads `mediaClassFor(src)`:
  `ProductArt`, `product-card`, `product-gallery`, `product-form` (thumb + preview),
  `products-table`, `set-form` (x2), `set-collage` (x4), `set-purchase-panel`,
  `search-dialog`, `account/page`, `wishlist-page-content`, `order-card`,
  `cart-line-item`, `account/orders/[code]`, `admin/orders/[code]`, `admin/page` (x2),
  plus raw `/art/*` hero/auth/editorial images tagged `media-invertible`.

**Verification:** `scripts/verify-light-images.mjs` (Playwright) reproduces the bug.
Before fix: computed `filter: invert(...)`, thumbnail pink. After fix: `filter: none`,
thumbnail true red; `/products/*.svg` art still gets `invert(...)`.
